Step 02Import ke Vercel

  1. Buka vercel.com → login pakai GitHub (haikarure).
  2. Add New → Project.
  3. Cari connectouch-official / ConnectAva → Import.
    Kalau gak muncul: klik Configure GitHub App → authorize org connectouch-official.
  4. Biarkan Vercel auto-detect Vite. Cek setting:
FieldValue
FrameworkVite
Root Directory/ (default)
Build Commandnpm run build
Output Directorydist
Install Commandnpm install

Vercel pakai npm (bukan bun). package-lock.json sudah ada di repo → install aman. Gak perlu vercel.json; Vite auto-detect SPA.

Step 05Custom domain (opsional)

  1. Dashboard Vercel → project → Settings → Domains.
  2. Add domain (mis. connectava.id).
  3. Ikuti instruksi DNS (CNAME / A record di registrar lu).
  4. SSL otomatis (Let's Encrypt) dari Vercel.

Step 06Update & re-deploy

Setiap push ke main → Vercel auto re-deploy. Untuk push update, copy website/ ke folder git terpisah (parent repo ai-avatar-yt gak diutak), lalu:

git add -A
git commit -m "update: ..."
git push origin main

Saran ke depan: pisahin website/ jadi git repo sendiri biar git push langsung dari situ tanpa copy manual.
